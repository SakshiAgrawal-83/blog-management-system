# Blog Management System

A full-stack Blog Management System developed using HTML, CSS, JavaScript, Node.js, and Express.js.

## Features

- Create Blog
- View Blogs
- Edit Blogs
- Delete Blogs
- Form Validation
- Fetch API Integration
- Responsive UI

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Node.js
- Express.js

## Project Structure

```
blog-management-system/
│── home.html
│── addBlog.html
│── style.css
│── home.js
│── script.js
│── index.js
│── package.json
```

## Installation

1. Clone the repository

```
git clone <repository-link>
```

2. Install dependencies

```
npm install
```

3. Run the project

```
node index.js
```

4. Open

```
http://localhost:3000/home.html
```

## Features Implemented

- Add Blog (POST)
- View Blogs (GET)
- Edit Blog (PUT)
- Delete Blog (DELETE)
